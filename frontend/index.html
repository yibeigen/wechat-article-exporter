Practical Features

智能广告与引流套话过滤

技术文章中经常混杂“长按扫码关注”、“点赞在看”、“本文首发于公众号”等营销尾巴。BlogDistiller 自动清洗这些干扰内容，完整保留代码块、数学公式与核心技术插图，输出清爽纯净的知识正文。

本地缓存与断点续爬

FAQ

常见问题与使用说明

这个工具的主要用途是什么？
主要解决两大痛点：1. 离线备份与个人阅读：将喜欢的技术博主历史文章一网打尽，做成整本 PDF 或离线电子书在本地阅读；2. AI 知识库语料构建：自动去除营销噪音，生成带标准 YAML 元数据和目录的 Markdown，直接喂给 Dify、FastGPT 或 Obsidian 等知识库。
抓取微信公众号文章需要配置什么吗？
支持两种便捷模式：1. 直接粘贴 URL：直接在输入框粘贴多篇公众号文章链接（每行一条），即可一键抓取并合并；2. 公众号全量遍历：在高级设置中填入微信公众平台后台的 Token 与 Cookie，即可通过官方超链接检索接口免风控、全自动遍历该公众号的所有历史文章。
文章被合并后，如何快速查看目录和定位章节？
导出的每个文件都内置了自动生成的结构化目录（TOC）：Markdown 文件顶部包含锚点目录树，HTML 文件内置自适应侧边栏目录与全文实时搜索，PDF 文件带有标准书签与页码索引。
如果抓取过程中断了，需要从头重新开始吗？
不需要。系统默认开启本地 SQLite 缓存与断点续爬机制，已经成功下载清洗过的文章会在本地缓存，重新执行时会直接秒级跳过已抓取内容，只抓取未完成的部分。
